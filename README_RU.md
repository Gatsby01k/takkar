# TAKKAR — Telegram Mini App

TAKKAR — браузерная impact-игра: игрок удерживает кнопку, раскручивает V12-механизм, отпускает сцепление, запускает тяжёлое колесо и решает после каждого удара — забрать текущий результат или рискнуть ещё раз.

## Запуск

```bash
npm start
```

Для локального режима:

```bash
npm run dev
```

Открыть `http://localhost:3000`.

## Управление

- Удерживать главную кнопку или `Space` — заряд двигателя.
- Отпустить — запуск.
- Главная зелёная кнопка или `C` — забрать результат.
- После завершения — запустить новый раунд.

## Версия 1.2.0

- телеметрия RPM / boost / speed / clutch;

- остановка сцены на impact-freeze;
- улучшенные искры, пыль, деформация и отдача;
- сохранённая мобильная адаптация.
